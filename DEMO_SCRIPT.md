# 2–3 Minute Demo Script

1. Introduce the Student Performance Prediction System.
2. Show the dataset and explain the academic features.
3. Explain preprocessing: missing values, duplicates, encoding and scaling.
4. Show the EDA charts.
5. Run the model training script and show saved metrics.
6. Open the Streamlit dashboard.
7. Enter a low-attendance/low-study-hours profile and show the prediction.
8. Show the recommendation section.
9. Change inputs to a stronger profile and demonstrate how the prediction changes.
10. End by showing the project structure and deployment instructions.
